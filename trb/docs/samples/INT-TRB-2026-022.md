# Review Intake Request: Model Serving

**Review ID:** TRB-2026-022 · **Feature:** `Model Serving@AI / ML` · **Databricks phase at submission:** GA
**Requesting business unit:** Research & Innovation · **Submitted:** 2026-09-21 · **Scheduled for:** TRBM-2026-10-06
**Primary reviewer:** CISO

## Business need
Research & Innovation submitted Model Serving for deploying trained models as low-latency APIs (e.g., real-time risk scoring on claims). TRB is reviewing network isolation and audit logging before scoring PHI.

## Intended use cases
- Real-time risk scoring on incoming claims
- Fraud detection APIs
- Member eligibility real-time check

## Risks identified by the requester
- API endpoint exposed to internet without auth
- Model input/output not logged for audit
- Inference latency violates claims SLA

## Proposed mitigations
- Model endpoints run in private network with VPC endpoint
- Request/response logging to audit tables with sampling
- P99 latency target: <100ms for risk scoring
