# Decision Record DR-2026-018: Databricks SQL

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-06-16
**Review:** TRB-2026-018 · **Feature:** `Databricks SQL@SQL & BI Analytics` · **Databricks phase at decision:** GA

## Context
Analytics Operations selected Databricks SQL (serverless warehouse) as the serving layer for analysts and BI tools querying PHI. TRB reviewed row/column filter enforcement and audit logging.

## Decision
Databricks SQL is approved as the enterprise serving layer for BI and analytics. All BI tool connections must go through SQL warehouses. Row and column filters are enforced at query time.

## Risks considered
- Filters bypassed if analysts query storage directly
- Warehouse concurrency limits at scale
- Audit log volume for high-query-rate environments

## Mitigations relied on
- External table access restricted; SQL warehouse required
- Warehouse queues configured per team SLA
- Audit sampling for cost control; 100% for PHI modifications

## Control mappings
- HIPAA-Security-Rule 164.312(a)(2)(i) (Unique user identification): Satisfied
- NIST-800-53-R5 AC-3 (Access Enforcement): Satisfied
- HITRUST-CSF 01.a (Information and Asset Management): Satisfied
