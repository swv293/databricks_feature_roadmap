# Decision Record DR-2026-033: Asset Bundles (DABs)

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-05-19
**Review:** TRB-2026-033 · **Feature:** `Asset Bundles (DABs)@Apps & Developer Tools` · **Databricks phase at decision:** GA

## Context
Enterprise Data Platform selected Asset Bundles (DABs) as the enterprise deployment standard for jobs, pipelines, and apps. TRB reviewed version control integration and rollback procedures.

## Decision
Asset Bundles are approved as the enterprise deployment standard. All production jobs and pipelines must be deployed via DABs. Manual resource creation is prohibited.

## Risks considered
- DAB validation doesn't catch breaking changes
- Rollback complexity for large bundles
- Production deployment coordination

## Mitigations relied on
- DAB syntax validation in pre-commit hooks
- Automated rollback via Git revert
- Deployment windows scheduled weekly

## Control mappings
- HIPAA-Security-Rule 164.308(a)(1)(ii)(b) (Information access management): Satisfied
- NIST-800-53-R5 CM-3 (Configuration Change Control): Satisfied
- HITRUST-CSF 09.c (Change Management): Satisfied
