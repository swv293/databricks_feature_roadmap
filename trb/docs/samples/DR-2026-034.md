# Decision Record DR-2026-034: Serverless compute

**Status:** Approved with Conditions · **Approved scope:** PHI (after all conditions close) · **Decided at:** TRBM-2026-06-16
**Review:** TRB-2026-034 · **Feature:** `Serverless compute@Compute` · **Databricks phase at decision:** GA

## Context
Finance selected Serverless Compute to reduce idle costs for bursty claims and reporting jobs. TRB is approving with conditions on compliance security profile validation and cost attribution.

## Decision
Serverless Compute is approved with conditions. PHI workloads require the compliance security profile enabled before production use. Condition COND-034-1 requires CSP GA on serverless; COND-034-2 requires cost attribution implementation; COND-034-3 requires performance baseline. Follow-up at 2026-08-16.

## Risks considered
- Compliance security profile not available on serverless
- Cost spikes from unlimited autoscaling
- Multi-tenant noisy-neighbor performance

## Mitigations relied on
- Compliance security profile roadmap confirms PHI support Q4 2026
- Spend controls via serverless job capacity reservations
- Isolated pools for high-priority workloads
