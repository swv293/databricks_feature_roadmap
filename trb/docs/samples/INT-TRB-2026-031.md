# Review Intake Request: SSO / SCIM

**Review ID:** TRB-2026-031 · **Feature:** `SSO / SCIM@Security & Networking` · **Databricks phase at submission:** GA
**Requesting business unit:** Information Security · **Submitted:** 2026-04-17 · **Scheduled for:** TRBM-2026-05-05
**Primary reviewer:** CISO

## Business need
Information Security proposed SSO and SCIM (via Okta) for centralized identity management and automatic deprovisioning. TRB reviewed IdP failover and access revocation timing.

## Intended use cases
- Centralized identity via IdP
- Automatic user provisioning and deprovisioning
- Single sign-on across Databricks

## Risks identified by the requester
- SSO outage blocks Databricks access
- SCIM sync lag delays deprovisioning
- Local accounts bypass SSO controls

## Proposed mitigations
- IdP redundancy via multiple Okta instances
- SCIM sync runs every 15 minutes; max 15-min lag
- Cluster policies forbid local user creation
