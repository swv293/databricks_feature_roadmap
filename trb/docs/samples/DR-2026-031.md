# Decision Record DR-2026-031: SSO / SCIM

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-05-05
**Review:** TRB-2026-031 · **Feature:** `SSO / SCIM@Security & Networking` · **Databricks phase at decision:** GA

## Context
Information Security proposed SSO and SCIM (via Okta) for centralized identity management and automatic deprovisioning. TRB reviewed IdP failover and access revocation timing.

## Decision
SSO and SCIM are approved and required for enterprise access control. All users must authenticate via Okta SSO. Local accounts are prohibited for PHI workspaces.

## Risks considered
- SSO outage blocks Databricks access
- SCIM sync lag delays deprovisioning
- Local accounts bypass SSO controls

## Mitigations relied on
- IdP redundancy via multiple Okta instances
- SCIM sync runs every 15 minutes; max 15-min lag
- Cluster policies forbid local user creation

## Control mappings
- HIPAA-Security-Rule 164.312(a)(2)(i) (Unique user identification): Satisfied
- NIST-800-53-R5 IA-2 (Authentication): Satisfied
- HITRUST-CSF 05.a (Access Control): Satisfied
