# TRB Meeting Minutes: 2026-05-19 (Platform baseline review)

**Attendees:** CISO, Chief Privacy Officer, Enterprise Architect, Platform Engineering Lead, Data Governance Lead, Compliance Officer · **Quorum:** met · **Format:** hybrid

## Decisions and introductions
### TRB-2026-029: HIPAA → **Approved** (scope: PHI)
Presented by Information Security; lead reviewer Compliance Officer.

The HIPAA profile is approved as the payer's standard security and privacy posture for PHI. All PHI workspaces must enable the compliance security profile with the HIPAA compliance standard selected, under the signed BAA.

### TRB-2026-030: Enhanced Security Monitoring → **Approved** (scope: PHI)
Presented by Information Security; lead reviewer CISO.

Enhanced Security Monitoring is approved for production PHI workloads on classic compute. ESM is required for all production clusters running PHI. ESM coverage for serverless compute is to be confirmed with the account team.

### TRB-2026-032: Databricks CLI → **Approved** (scope: PHI)
Presented by Enterprise Data Platform; lead reviewer Platform Engineering Lead.

The Databricks CLI is approved for platform-team tooling and automation. CLI is restricted to service-principal identities. Human API tokens are discouraged.

### TRB-2026-033: Asset Bundles (DABs) → **Approved** (scope: PHI)
Presented by Enterprise Data Platform; lead reviewer Enterprise Architect.

Asset Bundles are approved as the enterprise deployment standard. All production jobs and pipelines must be deployed via DABs. Manual resource creation is prohibited.
