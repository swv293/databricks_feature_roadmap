# Decision Record DR-2026-013: Auto Loader

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-06-02
**Review:** TRB-2026-013 · **Feature:** `Auto Loader@Ingestion` · **Databricks phase at decision:** GA

## Context
Claims Operations selected Auto Loader for continuous 837 EDI claim ingest and daily eligibility feeds. TRB evaluated file discovery mechanisms and guaranteed delivery semantics.

## Decision
Auto Loader is approved as the standard incremental ingestion path for claims and eligibility. File notification mode is required for high-volume EDI drops; directory listing is acceptable for lower-volume feeds.

## Risks considered
- File notification latency for high-volume drops
- Directory listing scalability at 10M+ files
- Duplicate handling edge cases

## Mitigations relied on
- File notification mode used for high-volume feeds
- Schema inference handles field additions automatically
- Duplicate detection via file path and checksum
