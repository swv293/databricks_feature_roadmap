# TRB Meeting Minutes: 2026-06-16 (Platform baseline review)

**Attendees:** CISO, Chief Privacy Officer, Enterprise Architect, Platform Engineering Lead, Data Governance Lead, Compliance Officer · **Quorum:** met · **Format:** hybrid

## Decisions and introductions
### TRB-2026-016: Delta Lake → **Approved** (scope: PHI)
Presented by Enterprise Data Platform; lead reviewer Enterprise Architect.

Delta Lake is approved as the default table format. All new tables use Delta unless approved for Iceberg. Time-travel and VACUUM retention are set per table to meet the records-retention policy.

### TRB-2026-018: Databricks SQL → **Approved** (scope: PHI)
Presented by Analytics Operations; lead reviewer Data Governance Lead.

Databricks SQL is approved as the enterprise serving layer for BI and analytics. All BI tool connections must go through SQL warehouses. Row and column filters are enforced at query time.

### TRB-2026-019: AI/BI Dashboards → **Approved** (scope: PHI)
Presented by Analytics Operations; lead reviewer Data Governance Lead.

AI/BI Dashboards are approved for internal governance and reporting with PHI filters. Dashboards must be built on UC tables with row/column masks enabled.

### TRB-2026-021: MLflow → **Approved** (scope: PHI)
Presented by Research & Innovation; lead reviewer Platform Engineering Lead.

MLflow is approved as the enterprise model registry and lifecycle system. All trained models must be logged to MLflow; promotion to production requires model-card sign-off.

### TRB-2026-034: Serverless compute → **Approved with Conditions** (scope: PHI (after all conditions close))
Presented by Finance; lead reviewer Enterprise Architect.

Serverless Compute is approved with conditions. PHI workloads require the compliance security profile enabled before production use. Condition COND-034-1 requires CSP GA on serverless; COND-034-2 requires cost attribution implementation; COND-034-3 requires performance baseline. Follow-up at 2026-08-16.
