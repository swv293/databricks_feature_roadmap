# Decision Record DR-2026-015: Lakeflow Jobs (Workflows)

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-06-02
**Review:** TRB-2026-015 · **Feature:** `Lakeflow Jobs (Workflows)@Pipelines & Data Engineering` · **Databricks phase at decision:** GA

## Context
Claims Operations and Finance jointly submitted Workflows (Lakeflow Jobs) as the enterprise orchestration engine. TRB evaluated task types, error handling, and audit logging.

## Decision
Workflows is approved as the enterprise standard for all scheduled and multi-step workloads. All production claims, eligibility, and reporting jobs must use Workflows.

## Risks considered
- Job dependencies not captured if manual coordination still used
- Timeout handling for long-running claims joins
- Audit trail for task-level retries

## Mitigations relied on
- Job DAG enforces explicit task dependencies
- Timeout limits configured per task type
- Each task execution logged to audit tables

- NIST-800-53-R5 AU-12 (Audit Record Generation): Satisfied
