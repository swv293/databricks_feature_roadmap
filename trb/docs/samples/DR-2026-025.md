# Decision Record DR-2026-025: Secure Cluster Connectivity (NPIP)

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-04-21
**Review:** TRB-2026-025 · **Feature:** `Secure Cluster Connectivity (NPIP)@Security & Networking` · **Databricks phase at decision:** GA

## Context
Information Security presented Secure Cluster Connectivity (no-public-IP / NPIP) as a baseline network control for production PHI workloads. TRB reviewed routing and internet access constraints.

## Decision
Secure Cluster Connectivity is approved and required for all production PHI workloads. All production clusters must have public IPs disabled.

## Risks considered
- Public IPs still assigned if not configured correctly
- Internet egress via NAT leaks IP source
- Egress filtering not enforced

## Mitigations relied on
- Cluster policies enforce no-public-IP setting
- NAT gateway restricted to approved destinations
- Egress firewall rules in network policies
