# Security & Privacy (HIPAA) Risk Assessment – Genie One

**Feature Name:** Genie One (Databricks SQL Generator)  
**Review ID:** TRB-2026-005  
**Assessment Date:** July 21, 2026  
**Assessed By:** Enterprise Architect  
**Overall Risk Level:** Moderate (mitigated to Low via conditions)  
**PHI-Eligible (Conditions Met)?** Conditional Yes

---

## 1. Executive Summary

Genie One is a natural-language SQL generator. Users ask questions in English; Genie generates SQL and returns results. Feature is GA. Risk centers on PHI leakage in user prompts (e.g., "Show me all patients with SSN 123-45-6789") and result set privacy (e.g., low-count aggregates revealing cohort members). Prompt/data handling to be verified during condition execution.

**With conditions (query logging, response masking, training), risk is acceptable for PHI use.**

---

## 2. Risk Assessment Context

### 2.1 System Boundaries

**In scope:**
- Genie One query generation and execution within Databricks workspace
- Natural-language prompts entered by users
- Query results displayed in Genie UI

**Out of scope:**
- Databricks infrastructure security (inherited AWS controls)
- User's laptop or network security

### 2.2 Data Classification

**Data Types:** Member demographics, claims (medical claims, mental health, pharmacy), membership status  
**Sensitivity:** PHI (HIPAA-regulated)  
**Volume:** ~3M member records; ~50M annual claims  
**Frequency:** Ad-hoc queries by 5-10 analytics users daily

## 4. Risk Analysis

### 4.1 Identified Risks

| # | Threat | Vulnerability | Likelihood | Impact | Risk Score | Mitigation |
|---|---|---|---|---|---|---|
| 1 | User enters PHI in prompt | Genie logs natural-language prompt; stored in audit table (could be accessed) | Medium | High | 9 | **COND-005-1:** Audit logging with access controls; prompts retained 180 days, access restricted to Compliance Officer |
| 2 | Genie response reveals low-count aggregate | E.g., "Members with X rare diagnosis: 1" reveals identity | Medium | Medium | 6 | **COND-005-3:** Monthly audit of result sets; TRB spot-checks 10 queries for low-count suppression |
| 3 | Unauthorized user queries member data | User credentials compromised or misused | Low | High | 5 | Access control via UC permissions; MFA on Databricks. Mitigated by standard identity controls. |
| 4 | Row-level filter bypass | User finds way to query unfiltered data | Low | High | 5 | **COND-005-2:** Test row filters with test identities; TRB spot-checks |
| 5 | User copies Genie result to unencrypted drive | Results exported outside Databricks | Low | Medium | 3 | **COND-005-4:** Training on data handling. Monitored via USB device restriction (IT controls). |

### 4.2 Risk Mitigation (Conditions)

| Condition ID | Mitigation | Effectiveness |
|---|---|---|
| COND-005-1 | Log all Genie queries (prompt, generated SQL, result count) to system tables; retain 180 days; restrict prompt access to Compliance Officer + CISO | High—enables breach investigation & pattern analysis |
| COND-005-2 | Row-level filtering enforced; TRB conducts test with 3 test identities to confirm masking works | High—prevents unauthorized row access |
| COND-005-3 | Monthly audit of 10 random Genie queries; check result set for low-count suppression (e.g., "n < 5" not displayed) | Medium—catches problematic queries; relies on manual review |
| COND-005-4 | All users complete "Databricks + HIPAA Data Handling" training before Genie access; refresher annually | Medium—awareness reduces accidental disclosure; enforcement via access control |

## 5. Residual Risk Statement

**After conditions are met, residual risk is LOW.**

- **User Prompt PHI Leakage:** Mitigated by training + audit logging. Residual: User forgets training or deliberately discloses (very low likelihood).
- **Response Privacy:** Audit sampling catches most low-count issues. Residual: Unknown/hard-to-detect patterns (very low).
- **Unauthorized Access:** UC row filters + MFA reduce to baseline identity compromise risk (low for this organization).

**Assumption:** Acme Health Plan maintains standard IT security controls (patch management, endpoint protection, incident response). If these degrade, residual risk increases.
