# Review Intake Request: Databricks SQL

**Review ID:** TRB-2026-018 · **Feature:** `Databricks SQL@SQL & BI Analytics` · **Databricks phase at submission:** GA
**Requesting business unit:** Analytics Operations · **Submitted:** 2026-05-29 · **Scheduled for:** TRBM-2026-06-16
**Primary reviewer:** Data Governance Lead

## Business need
Analytics Operations selected Databricks SQL (serverless warehouse) as the serving layer for analysts and BI tools querying PHI. TRB reviewed row/column filter enforcement and audit logging.

## Intended use cases
- BI tool connections (Tableau, Looker)
- Ad-hoc analyst queries
- Scheduled reporting SQL

## Risks identified by the requester
- Filters bypassed if analysts query storage directly
- Warehouse concurrency limits at scale
- Audit log volume for high-query-rate environments

## Proposed mitigations
- External table access restricted; SQL warehouse required
- Warehouse queues configured per team SLA
- Audit sampling for cost control; 100% for PHI modifications
