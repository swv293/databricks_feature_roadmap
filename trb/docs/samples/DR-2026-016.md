# Decision Record DR-2026-016: Delta Lake

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-06-16
**Review:** TRB-2026-016 · **Feature:** `Delta Lake@Storage & Formats` · **Databricks phase at decision:** GA

## Context
Enterprise Data Platform designated Delta as the default table format for all PHI workloads. TRB reviewed ACID guarantees, time-travel retention, and interoperability.

## Decision
Delta Lake is approved as the default table format. All new tables use Delta unless approved for Iceberg. Time-travel and VACUUM retention are set per table to meet the records-retention policy.

## Risks considered
- Time-travel retention increases storage cost
- Format lock-in vs. open formats
- Upgrade complexity for large tables

## Mitigations relied on
- VACUUM policy: 180-day retention for PHI, 30 days for analytics
- Iceberg interoperability via UniForm
- Delta version checks automated in CI/CD
