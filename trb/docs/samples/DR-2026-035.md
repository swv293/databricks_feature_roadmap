# Decision Record DR-2026-035: Classic compute

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-06-30
**Review:** TRB-2026-035 · **Feature:** `Classic compute@Compute` · **Databricks phase at decision:** GA

## Context
Enterprise Data Platform maintains Classic Compute as a strategic compute option for workloads requiring specific instance types or network controls not available via serverless.

## Decision
Classic Compute is approved for production workloads where serverless is not suitable. Cluster policies are required; all production clusters must use an approved Databricks Runtime LTS version, with Photon where supported.

## Risks considered
- Idle cluster cost drift
- Cluster configuration drift vs. policy
- Dependency on legacy cluster manager

## Mitigations relied on
- Cluster auto-termination policies enforced
- Cluster policies lock critical settings
- Gradual migration to serverless as gaps close

- NIST-800-53-R5 CM-6 (Configuration Settings): Satisfied
