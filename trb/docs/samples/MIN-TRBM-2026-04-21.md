# TRB Meeting Minutes: 2026-04-21 (Platform baseline review)

**Attendees:** CISO, Chief Privacy Officer, Enterprise Architect, Platform Engineering Lead, Data Governance Lead, Compliance Officer · **Quorum:** met · **Format:** hybrid

## Decisions and introductions
### TRB-2026-025: Secure Cluster Connectivity (NPIP) → **Approved** (scope: PHI)
Presented by Information Security; lead reviewer CISO.

Secure Cluster Connectivity is approved and required for all production PHI workloads. All production clusters must have public IPs disabled.

### TRB-2026-026: PrivateLink (front-end & back-end) → **Approved** (scope: PHI)
Presented by Information Security; lead reviewer CISO.

PrivateLink is approved as a core requirement for the payer's PHI environment. Dual PrivateLink (front and back) is required for production PHI. Single PrivateLink is acceptable for non-PHI analytics.

### TRB-2026-027: Customer-managed keys (CMK) → **Approved** (scope: PHI)
Presented by Information Security; lead reviewer CISO.

Customer-managed keys are approved and required for all PHI data at rest. Encryption must use CMK; AWS default keys are not acceptable for PHI.

### TRB-2026-028: Compliance security profile → **Approved** (scope: PHI)
Presented by Information Security; lead reviewer Compliance Officer.

The Compliance Security Profile is approved and required for all PHI workloads. Once enabled on a workspace, it cannot be disabled. All production PHI workspaces must have CSP enabled.
