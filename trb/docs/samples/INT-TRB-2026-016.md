# Review Intake Request: Delta Lake

**Review ID:** TRB-2026-016 · **Feature:** `Delta Lake@Storage & Formats` · **Databricks phase at submission:** GA
**Requesting business unit:** Enterprise Data Platform · **Submitted:** 2026-05-28 · **Scheduled for:** TRBM-2026-06-16
**Primary reviewer:** Enterprise Architect

## Business need
Enterprise Data Platform designated Delta as the default table format for all PHI workloads. TRB reviewed ACID guarantees, time-travel retention, and interoperability.

## Intended use cases
- All claims and member storage
- Time travel for audit and recovery
- ACID upserts for incremental updates

## Risks identified by the requester
- Time-travel retention increases storage cost
- Format lock-in vs. open formats
- Upgrade complexity for large tables

## Proposed mitigations
- VACUUM policy: 180-day retention for PHI, 30 days for analytics
- Iceberg interoperability via UniForm
- Delta version checks automated in CI/CD
