# Decision Record DR-2026-032: Databricks CLI

**Status:** Approved · **Approved scope:** PHI · **Decided at:** TRBM-2026-05-19
**Review:** TRB-2026-032 · **Feature:** `Databricks CLI@Apps & Developer Tools` · **Databricks phase at decision:** GA

## Context
Enterprise Data Platform submitted Databricks CLI for automation and this tracker's weekly refresh workflow. TRB reviewed credential handling and audit logging.

## Decision
The Databricks CLI is approved for platform-team tooling and automation. CLI is restricted to service-principal identities. Human API tokens are discouraged.

## Risks considered
- API token lifetime and rotation
- CLI audit trail sparse vs. web console
- Token compromise in CI/CD pipelines

## Mitigations relied on
- API tokens limited to service principals with short TTL
- CLI calls logged via audit tables
- GitHub Actions tokens use temporary credentials

## Control mappings
- HIPAA-Security-Rule 164.312(a)(2)(i) (Unique user identification): Satisfied
- NIST-800-53-R5 AC-2 (Account Management): Satisfied
- HITRUST-CSF 05.a (Access Control): Satisfied
