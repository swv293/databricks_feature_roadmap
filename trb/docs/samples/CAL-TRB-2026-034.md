# Conditional Approval Letter: Serverless compute

To: Finance · From: Tech Review Board · Re: TRB-2026-034 · Date: 2026-06-16

The TRB approved **Serverless compute** with conditions at TRBM-2026-06-16. The approval does **not** permit PHI use
until every condition below is verified closed and the TRB moves the review to Approved.

| ID | Condition | Requirement | Verification | Due |
|---|---|---|---|---|
| COND-034-1 | Compliance Security Profile (CSP) GA on Serverless | Databricks must release CSP support for serverless compute. PHI workloads are blocked until CSP is GA and validated on serverless. | Databricks product release notes and feature availability documentation | 2026-12-31 |
| COND-034-2 | Cost Attribution to Claims Operations | Implement cost allocation for serverless jobs so Claims Operations can track DBU spend. Tagging must enable per-job and per-team cost reporting. | Cost analysis report showing serverless job costs tagged by team and workload | 2026-08-16 |
| COND-034-3 | Performance Baseline for Claims Jobs | Run 5 pilot claims jobs on serverless (100-500GB datasets) and document P50/P99 latency vs. classic compute. Startup overhead must be <5 min. | Performance benchmark report with job latency distributions and startup times | 2026-07-16 |

Rationale: Serverless Compute is approved with conditions. PHI workloads require the compliance security profile enabled before production use. Condition COND-034-1 requires CSP GA on serverless; COND-034-2 requires cost attribution implementation; COND-034-3 requires performance baseline. Follow-up at 2026-08-16.
