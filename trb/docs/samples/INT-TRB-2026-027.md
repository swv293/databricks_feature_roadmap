# Review Intake Request: Customer-managed keys (CMK)

**Review ID:** TRB-2026-027 · **Feature:** `Customer-managed keys (CMK)@Security & Networking` · **Databricks phase at submission:** GA
**Requesting business unit:** Information Security · **Submitted:** 2026-04-04 · **Scheduled for:** TRBM-2026-04-21
**Primary reviewer:** CISO

## Business need
Information Security selected Customer-Managed Keys (CMK) for encrypting PHI at rest. TRB reviewed key lifecycle, HSM support, and key rotation automation.

## Intended use cases
- Key ownership for regulated data
- Encryption at rest with payer-controlled keys
- Key rotation and revocation

## Risks identified by the requester
- Key loss disables all encrypted data
- Rotation complexity for multi-region deployments
- KMS authorization bypass

## Proposed mitigations
- Keys backed up in AWS KMS secure vault
- Automated rotation via KMS key policy
- KMS access controlled via IAM + UC external locations
