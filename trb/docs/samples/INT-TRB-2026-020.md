# Review Intake Request: AI/BI Genie

**Review ID:** TRB-2026-020 · **Feature:** `AI/BI Genie@SQL & BI Analytics` · **Databricks phase at submission:** GA
**Requesting business unit:** Analytics Operations · **Submitted:** 2026-09-20 · **Scheduled for:** TRBM-2026-10-06
**Primary reviewer:** Chief Privacy Officer

## Business need
Analytics Operations submitted AI/BI Genie (natural-language Q&A) as an umbrella review for analyst self-serve access to PHI. Genie One (TRB-2026-005) is an existing approved use case. TRB is evaluating whether UC row/column masks and filters are proven to hold in Genie-generated SQL.

## Intended use cases
- Analyst self-serve Q&A over PHI
- HEDIS/STARS metric queries
- Ad-hoc member cohort analysis

## Risks identified by the requester
- Generated SQL bypasses row/column filters
- LLM prompt injection exposes schema or data
- Genie answer cache leaks PHI between users

## Proposed mitigations
- Genie SQL generation goes through UC masking validation
- User prompt validation and sanitization before LLM
- Query result cache isolated per user with TTL
