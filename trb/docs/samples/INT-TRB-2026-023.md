## Business need
Analytics Operations submitted AI Functions (SQL) for calling foundation models directly from SQL to classify, extract, and summarize at scale. TRB is reviewing which foundation models are approved for PHI-bearing prompts.

## Intended use cases
- Appeal letter classification and summarization
- Diagnosis code extraction from clinical notes
- Member sentiment from feedback surveys

## Risks identified by the requester
- LLM training data includes customer prompts and outputs
- Uncontrolled model drift affects classification accuracy
- Prompt injection reveals PII in classification result

## Proposed mitigations
- Foundation models vetted for no-training-data-retention guarantees
- Model versioning controlled via Databricks Foundation Model API
- Input sanitization and prompt injection validation
