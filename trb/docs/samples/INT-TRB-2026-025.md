# Review Intake Request: Secure Cluster Connectivity (NPIP)

**Review ID:** TRB-2026-025 · **Feature:** `Secure Cluster Connectivity (NPIP)@Security & Networking` · **Databricks phase at submission:** GA
**Requesting business unit:** Information Security · **Submitted:** 2026-04-02 · **Scheduled for:** TRBM-2026-04-21
**Primary reviewer:** CISO

## Business need
Information Security presented Secure Cluster Connectivity (no-public-IP / NPIP) as a baseline network control for production PHI workloads. TRB reviewed routing and internet access constraints.

## Intended use cases
- No-public-IP compute for PHI workloads
- Network segmentation baseline
- Reduced internet egress exposure

## Risks identified by the requester
- Public IPs still assigned if not configured correctly
- Internet egress via NAT leaks IP source
- Egress filtering not enforced

## Proposed mitigations
- Cluster policies enforce no-public-IP setting
- NAT gateway restricted to approved destinations
- Egress firewall rules in network policies
